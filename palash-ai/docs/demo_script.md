2. Disable Wi-Fi and mobile data, then point out the Offline mode banner.
3. Open Lessons, select Grade 1 Numeracy, and open Counting 1-10.
4. Show the Hindi instruction and its prototype Santali translation.
5. Open Voice Translator. Select a demo Hindi phrase, record it, then stop recording.
6. Show the mock ASR transcription, offline translation, mock audio cue, and measured timings.
7. Open Worksheet Generator and create a bilingual PDF locally.
8. Open Flashcards and generate local number cards.

10. Open Progress and mark a lesson complete. Explain that it is stored locally.
11. Reconfirm that all lesson and demo functions remain available offline.
